## 📂 Structure

Each topic has its own folder. Every solved problem is its own file, named after the problem, with a short header comment describing the problem and its source.

```
dsa-practice/
├── basic_recursion/
│   └── print_name_n_times.py
├── arrays/
├── strings/
└── README.md
```
